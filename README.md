Stock App UI Analysis

This project analyzes user reviews of stock trading applications using Python. The purpose is to understand user sentiment and identify common UI and UX issues through text mining techniques. The results aim to provide insights for improving interface design and user experience.

Research Objectives

The main objectives of this project are to analyze user sentiment toward stock apps, identify frequently mentioned UI and UX problems, and explore visual design factors such as layout, color, and readability. The study also aims to translate these findings into practical design suggestions.

Methodology

The project consists of three main stages. First, user reviews are collected from the Google Play Store using a web scraping tool. The collected data includes review content, ratings, and timestamps.

Second, the data is cleaned and preprocessed. This includes removing unnecessary symbols, filtering invalid data, and preparing the text for analysis.

Third, text analysis is conducted. Sentiment analysis is used to classify reviews into positive, negative, and neutral categories. In addition, user comments are categorized into different types of UI issues, including usability, performance, functionality, visual design, and others. For visual design, further classification is applied to identify specific aspects such as font readability, color usage, button design, layout, and overall interface design.

Project Structure

The project includes crawler scripts for collecting data from different stock apps, analysis scripts for processing and analyzing the data, and CSV files that store both raw and processed results.

Results Summary

The analysis shows that user feedback is mixed across different stock apps. Negative reviews are often related to system performance issues, bugs, and difficulties in operation. In terms of UI and UX, common problems include lagging interfaces, unclear navigation, and complicated interaction flows.

From a visual design perspective, users frequently mention issues related to unclear layout, poor readability, and ineffective color combinations. These findings highlight the importance of clear information hierarchy and intuitive design.

Key Contributions

This project combines web scraping and text mining techniques to analyze user-generated content. It focuses specifically on UI and UX issues rather than general sentiment analysis. The classification approach provides a structured way to understand user feedback and supports data-driven interface design improvements.

Future Work

Future research can expand the data sources to include platforms such as the App Store and online forums. More advanced text analysis methods, such as topic modeling or machine learning techniques, can also be applied. In addition, the study can be extended to compare multiple stock apps or integrate AI-based analysis for deeper insights.

Tools and Technologies

The project is implemented using Python. Key tools include Pandas for data processing and Google Play Scraper for data collection. Text mining techniques are applied for analysis.
